# Ashes of Empires, Loop Lessons

Living memory for the Muse takeover build loop (started 2026-10-15, Jash's order). Read at the start of every run. Append at the end of every run: what failed and why, what pattern worked, what to try or avoid next time. If a lesson proves wrong, strike it through with a dated note instead of deleting it.

## Lessons

- 2026-10-15, reconciliation discovery: the GitHub branch state in the takeover brief (about 10 ahead, 4 behind) was stale by the time the first takeover run checked it. The branch claude/adoring-johnson-cf5bmq is in fact 136 commits ahead of remote master and 0 behind, because it was rebased onto master's Cycle 6 step 5 commit and then kept building through Cycles 7 to 17 on 2026-10-13 and 2026-10-14. Lesson: never trust a brief's branch counts. Measure the branch with the compare API at the start of reconciliation and log the measured counts.
- 2026-10-15, gh.py path bug: the GitHub fetch script inserts a wrong sys.path (templates/skill/bin) and fails with ModuleNotFoundError for dynamic_credentials on a plain run. Setting PYTHONPATH to /opt/muse/skills/custom-connector-setup/bin makes the exact script named in the mission work without editing it. Use that prefix for every gh.py call in this loop.
- 2026-10-15, port in authored slice order, but assess before replacing: the branch's first reconciliation slice added a balance harness, but master gained its own committed harness in Cycle 6 step 5 (commit 797b1b8) that reproduces the verified step 4 numbers. Overwriting it blindly would have traded a verified harness for an unverified one. Diff before treating a branch item as unique, exactly as the mission warned for tools/balance.js.
- 2026-10-15, test-only slices are the safest first port: the drawn in defender reversal test (slice 2) applied as a pure append, passed on master unchanged (40 of 40), and changed no balance numbers. When a reconciliation contains a test that pins a behavior master already claims, port the test early; it turns a claimed behavior into a pinned one.
- 2026-10-15, a branch harness that gates on profiles that fail is information, not a defect to hide: the branch slice 1 harness records that its no factory script loses seed 31337 and its factory path won only 1 of 8 on the pre slice sim. Those failures are what slices 4 (research clock) and 5 (lines paid before factories) were built to fix. Do not port the gating harness before the sim slices it depends on, or the repo will carry a red gate with no fix in the same step.
- 2026-10-15, gh.py fetch is not idempotent over a dirty destination: a leftover extracted directory in /tmp/ashes-gh-sync made the fetch fail with a rename Directory not empty error partway through, leaving a half synced copy that looked like a real diff. Lesson: rm -rf /tmp/ashes-gh-sync before every fetch, and never trust a diff from a fetch that exited non-zero.
- 2026-10-15, branch commit patches are fetchable one at a time through the GitHub commits API with the same surrogate credential gh.py uses: GET /repos/jashshah854-a11y/ashes-game/commits/<sha> returns the full per file patch. That is the clean way to port one authored slice verbatim without fetching the whole 136 commit branch.
